# 将来の開発段階（提案、未実施）

## Phase 0: 本リリース
ディレクトリ分離、リンク置換、コード原本保全、GitHub向け文書・検証手段。

## Phase 1: 不変条件と回帰テストの充実
実機スクリーンショットとクリックテストをベースライン化。メニュー、財政グラフ、地域絞込、記事ナビなどの主要操作を自動化。

## Phase 2: 責務ごとのコード整理
巨大な `commons-content.js` や `site.css`、機能エンジンを段階的に整理。JSのグローバル依存を明文化し、変更単位ごとにブラウザ比較を実施。見え方が変わるCSSの置換は機能改修と分ける。

## Phase 3: 構造化データへ移行
記事、財政統計、事業を必要に応じてJSON/CSV/GeoJSON化。元データと表示結果を厳密に照合。出典、対象期間、更新履歴を付与。

## Phase 4: 新しいインタラクティブな地図
人口・公共交通などの地図レイヤーとスライダーを独立機能として追加。実績/公的推計/独自仮定を混同しない。既存ページを変えない別ブランチで先行開発。

## Phase 5: 共同開発と公開
GitHubのIssues/PRで役割分担。独自ドメインを別途用意し、ホスティング環境を交換できる構造を維持。原則、公開はレビュー後に行う。
