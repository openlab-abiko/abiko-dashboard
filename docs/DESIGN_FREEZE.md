# v0.82 保全基準（デザイン・機能固定）

この構成整理では、以下を変更対象から除外しています。

- 文章、数値、注記、ラベル、リンクの表示内容
- 全ページと21記事のHTML構造、並び、カード、配色、余白、フォント、アニメーション
- ナビゲーション、ページ移動、絞り込み、グラフ、保存、記事参照などの操作
- 既存のページURL、`articles/*.html` のURL
- 各ページのCSS/JS読み込み**順番**とソースのバイト列
- 行政データ、参照先URL、日付情報

**実施した変更:** HTMLの静的なCSS/JS参照パスを付け替え、ファイルを役割別のディレクトリに配置しました。全CSS/JS/JSONの中身はソース原本と完全一致のはずです。変更前後のSHA-256、HTML正規化比較とブラウザの画像比較で検証します。

**今後の独立作業:** CSSの統合・共通化、JSのモジュール化、データセット外出し、アクセシビリティ・パフォーマンス改善はリスクがあるため、別ブランチで段階的に検証して実施してください。

**本資料の保証範囲:** 自動試験を通過しても、すべての端末・ブラウザ・外部サービスの同一表示を数学的に保証できるわけではありません。未テスト項目は別途報告します。
